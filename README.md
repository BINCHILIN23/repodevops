primer proyect





Este es mi primer proyecto utilizando Git y GitHub.





Instalación



Para utilizar este proyecto se debe clonar el repositorio.



git init

Sirve para iniciar un nuevo repositorio de Git en una carpeta.



git add

Sirve para preparar los archivos que quiero incluir en el próximo commit.



git commit

Sirve para guardar los cambios realizados en el historial del proyecto.



git push

Sirve para enviar los commits de mi computador al repositorio de GitHub.



git status

Sirve para revisar el estado actual del proyecto y saber qué archivos han cambiado o cuáles todavía no han sido agregados.



git diff

Sirve para ver exactamente qué cambios se han realizado en los archivos desde el último commit.



git log

Sirve para ver el historial de commits realizados en el proyecto.



git restore

Sirve para deshacer cambios que todavía no han sido guardados en un commit.
